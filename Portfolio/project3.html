Business Intelligence & Data Warehouse

BI - Data Warehouse - SSIS - SSAS - PowerBI - ETL - OLAP - Data Modeling - SQLServer

COURSE PROJECT - Team size: 4

Objective

Design and implement a data warehouse system to collect, transform, and analyze Air Quality Index (AQI) data across multiple states and time periods.

Implementation

  • Designed a Star/Snowflake schema based on OLTP and analytical requirements.
  • Developed ETL pipelines using SSIS to extract, transform, and load data into a centralized warehouse.
  • Created OLAP cubes with SSAS for multidimensional analysis.
  • Built interactive dashboards with Power BI for business insights.

Result

  • Completed full BI workflow: Data Modeling → ETL → OLAP → Visualization.
  • Enabled state-level and seasonal insights into PM2.5, O₃, and CO levels.
  • Improved analytical visibility and decision-making for environmental monitoring use cases.
