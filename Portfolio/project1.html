Real-Time Credit Card Transaction Analytics

Kafka - Spark Streaming - Airflow - Hadoop - Power BI - Data Pipeline - Realtime Analytics

COURSE PROJECT - Team size: 4

Objective

Develop a real-time data processing system to detect abnormal transaction patterns and support fraud monitoring.

Implementation

  • Set up Kafka to stream transaction data from CSV files in real time.
  • Used Spark Streaming for continuous data processing and aggregation.
  • Stored data in Hadoop HDFS for large-scale analysis and reporting.
  • Automated workflow orchestration using Apache Airflow (DAG scheduling).
  • Designed Power BI dashboards visualizing key metrics: total transactions, regional distribution, error rates, and anomaly alerts.

Result

  • Successfully built an end-to-end real-time data pipeline with low latency.
  • Power BI dashboards enabled 50% faster anomaly detection compared to manual review.
  • Demonstrated the full data lifecycle: Ingestion → Processing → Visualization.
