Healthcare Analytics Power BI Dashboard

Power BI - Healthcare Analytics - Data Visualization - ETL - DAX - Data Modeling

PERSONAL PROJECT

Objective

To design an end-to-end interactive analytics solution for a healthcare dataset that provides insights into patient admissions, hospital performance, medication usage, insurance billing, and time-based trends.

The goal was to transform raw admission data into a dynamic Power BI report that supports both operational and strategic decision-making for hospital management.

Implementation

  • Data Modeling: Built a Star schema model.
  • Data Transformation: Applied Power Query for data cleaning and standardization.
  • Calculated Metrics: Developed DAX measures for KPIs like Total Patients, Average Billing, and Length of Stay.
  • Visualization: Created interactive dashboards with slicers, charts, and tables.

Result

  • Developed a comprehensive Power BI dashboard enabling multi-dimensional analysis of healthcare data.
  • Provided actionable insights into patient demographics, hospital performance, and financial metrics.
  • Facilitated data-driven decision-making for hospital administrators and healthcare professionals.
